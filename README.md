## 1. 程式用途與執行方式
本程式是一個簡單的聚餐費用試算器，能夠自動清理含有雜訊的原始字串資料（如去除貨幣符號、逗號與前後空白），進行型別轉換，並依規則計算 10% 服務費、扣除折價券後的應付總額、每人分攤金額，最後透過布林運算判斷是否超過每人 300 元的預算限制。

## 3. 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**答：** 因為 `"4"` 在 Python 中屬於字串（`str`）型別。字串雖然外觀是數字，但電腦無法直接對字串進行數學除法運算（若直接執行 `1220 / "4"` 會引發 `TypeError`）。因此必須先透過 `int()` 將其轉換為整數型別，才能正確進行分攤金額的算術運算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：** 
* **計算結果：** 若先扣折價券（$1,200 - 100 = 1,100$），再計算 10% 服務費（$1,100 \times 1.1 = 1,210$），應付總額會變成 **1,210 元**（比題目的 1,220 元少 10 元）。
* **不同原因：** 餐廳的服務費通常是以未折價前的原始餐費作為計算基底（即服務生提供服務的勞務價值不因店家發放折價券而減少）。如果先扣折價券再算服務費，等於讓折價券額度同時折抵了原本應計收的服務費，這與一般餐廳的計費邏輯與題目規定的計算順序（先算服務費、再扣折價券）不符。
